# Peek website

Minimal marketing site for **Peek** — Face unlock for Mac.

## Preview

```bash
cd website
python3 -m http.server 8080
```

## Deploy

```bash
cd website
npx vercel --prod
```

## Download

The site links to the latest GitHub Release DMG:

https://github.com/XIVASSS/peek/releases/latest/download/Peek.dmg
